# Launch copy: held pending release approval

CorrLog creates signed records of agent actions, corrections and uncertainty.
Records can be verified offline against an independently trusted public key.
Verification detects changes to signed record content; it does not prove that
statements are true or that every event was recorded.

JSONL receipt files are not tamper-evident ledgers. See RELEASE_READINESS.md for
version-specific evidence, limitations and claims to avoid. Do not publish this
candidate or announce production readiness without release approval.
